# Walls & Dreams — Design-Build Homes Website

**WD Design-Build Collection 2026** — A polished, full-page static website for Walls & Dreams Private Limited, a customer-obsessed design-build home construction company based in Noida, Delhi NCR.

---

## 🏠 Project Overview

**Brand**: Walls & Dreams Private Limited  
**Tagline**: Build With Clarity. Build With Control.  
**Location**: Noida, Delhi NCR  
**Contact**: hello@wallsanddreams.com | +91 98765 43210

The website is structured, transparent, and professionally managed — mirroring the company's core values. Design direction follows the reference: https://vishnut2003.github.io/wd-new-home/final-home-design/

---

## ✅ Completed Features

### Sections (in page order):
1. **Header** — Dual-bar (utility + main nav), sticky on scroll, mobile hamburger menu
2. **Hero** — Full-bleed dark image bg, headline + USP copy, avatar trust stack, hero features, glass consultation form
3. **Stats Bento** — 5-tile bento grid: 350+ checks, 10Yr warranty, 24/7 CCTV, 100% in-house, 5-phase process
4. **Why Us** — 9-card drag-scroll carousel with prev/next/dots controls
5. **🔴 The Walls & Dreams Way** — NEW 5-step branded process section (dark, immersive):
   - Phase 01: Discovery
   - Phase 02: Value Benchmarking
   - Phase 03: Commitment
   - Phase 04: Execution & Monitoring
   - Phase 05: Handover & Support
6. **Design Families** — 4-tile bento mosaic (Atmos Blue, Alive Green, Avenue Beige, Ambience Black)
7. **Packages** — 4-card grid with photos, pricing, features, CTA buttons
8. **Integrated Execution System** — Dark section with 6 capability cards
9. **Structural Integrity** — 6-item grid, non-negotiable specs
10. **Why Choose Walls & Dreams** — Comparison table vs. competitors
11. **Testimonials** — 4 client quote cards
12. **Team** — 4-member team card grid
13. **FAQ** — 8-item accordion (2-column layout)
14. **Home Loan Assistance** — 3 bank tiles (HDFC, Axis, SBI)
15. **WD Difference** — 3 differentiator cards + promise block
16. **Final CTA** — Dark section with dual CTAs
17. **Footer** — Brand, explore, services, contact columns + copyright

### Interactive Features:
- ✅ Sticky header with scroll shadow
- ✅ Mobile hamburger nav (drawer-style)
- ✅ Why Us carousel with drag/touch/keyboard support
- ✅ FAQ accordion
- ✅ Scroll-reveal animations on all cards
- ✅ Form submission with loading state and success feedback
- ✅ Smooth anchor scrolling with header offset
- ✅ Hover effects on all interactive elements

## 🎨 Design System

**Typography**: Plus Jakarta Sans (Google Fonts — 300–800 weights)  
**Primary Color**: `#F9312F` (WD Red)  
**Dark**: `#0A0A0A` / `#000`  
**Light**: `#FAFAF8` / `#F5F5F3`  
**Border Radius**: 20px (cards), 14px (small), 8px (inputs)  
**Max Width**: 1280px
